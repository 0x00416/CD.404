# CD.404 真实硬件验证手册

本文把自动化保证、已观察硬件和仍需发布候选补测的项目分开。任何 `SKIP`、未执行或
缺少采集设备的条目都不能记作通过。

## WASAPI 探针

先构建含诊断工具的 Debug 配置：

```powershell
make debug
.\out\build\ninja-msvc-x64\tools\probes\wasapi\cd404_wasapi_probe.exe --list
```

工具默认只枚举活动渲染端点。没有端点时打印 `SKIP` 并返回 2；枚举/初始化失败返回 1。
可把 `--endpoint` 后的完整稳定 ID 传给以下命令，省略时使用当前多媒体默认端点。

### 共享模式回环

```powershell
.\out\build\ninja-msvc-x64\tools\probes\wasapi\cd404_wasapi_probe.exe --loopback-shared
```

命令先启动同一渲染端点的 Windows 共享回环，再输出一秒 997 Hz、左右反相、前后各
50 ms 静音的固定标记。通过条件为：渲染正常排空、至少捕获半秒混音格式帧、存在
非静音数据，且首包之后没有 `DATA_DISCONTINUITY`。该检查验证连续传输，不声称验证
共享混音器转换后的逐位相等。

### 独占模式

```powershell
.\out\build\ninja-msvc-x64\tools\probes\wasapi\cd404_wasapi_probe.exe --render-exclusive
```

Windows 回环不能在同一端点被独占时作为可靠采集依据。命令只证明设备接受并排空
44,100 个原生格式精确帧；端到端验证需把所选端点接到独立录音接口，录制固定标记，
检查起止静音、997 Hz 主频、左右反相、无跳变/重复，并记录设备、驱动、Windows 版本、
缓冲周期和录音文件 SHA-256。不得把听感检查写成位精确通过。

## 光驱与设备生命周期矩阵

每个发布候选至少在 Windows 10 与 Windows 11 各一台普通用户权限设备上执行：

1. 实体音频 CD 连续跨越相邻轨边界 20 次，记录光驱型号、读取重试、重叠不一致、生产
   饥饿和端点欠载；任何插帧、短读被修饰或未解释失败均不通过。
2. 播放中拔盘、换成另一张盘、重新插回原盘；验证协作停止、过期 UI 清除、不同盘不
   自动播放且资源释放后可重新打开。
3. 播放中切换系统默认端点、禁用所选端点、再恢复；验证默认端点只自动重试一次，
   固定端点显示失效原因，UI 的请求模式/实际模式/回退原因准确。
4. 播放和暂停状态分别休眠/唤醒；只有唤醒后重新验证为同一张盘且休眠前正在播放时
   自动续播，暂停态保持暂停，换盘不续播。
5. 共享/独占各执行停止、连续切轨、定位和异常退出 50 次，用进程句柄/线程观察确认
   光驱句柄、COM 端点、事件和线程均回到基线。

## 本次环境观察（2026-08-09）

- 自动测试：两套固定种子各 4,096 次压力路径通过；HTTP、WASAPI 策略和设备生命周期
  外部边界均可注入，无公网或光驱也能重复运行。
- 真实音频：默认 Minifuse 端点共享回环捕获 57,330 帧（44.1 kHz 混音格式）、
  335,290 个非零字节、无不连续标志；独占模式提交并排空 44,100 个精确 PCM 帧。
- 未覆盖：本会话没有可用光驱/介质；未执行独占外部采集、默认端点切换、拔盘/换盘和
  休眠/唤醒。上述项目保留为公开测试发布风险，不能写成通过。
