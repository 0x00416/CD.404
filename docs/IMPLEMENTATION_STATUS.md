# 实施状态

## 当前里程碑

## 已完成

- 初始化 C++20/CMake 工程。
- 添加 Visual Studio 2026 x64 和 Ninja/MSVC 构建预设。
- 添加空的 vcpkg manifest，为后续按项目锁定第三方依赖预留入口。
- 实现 CDDA 常量及 MSF、绝对扇区、LBA、采样帧转换。
- 实现转换范围和乘法溢出检查。
- 实现平台无关 TOC 模型、轨号连续性、轨道位置和 lead-out 验证。
- 从 TOC 自动计算轨道结束 LBA、整盘起始采样帧和轨道采样帧数。
- 实现 Windows 光驱枚举。
- 使用 `IOCTL_CDROM_READ_TOC_EX` 读取原生 TOC 并转换为平台无关模型。
- 实现命令行光驱探针。
- 定义平台无关的 CDDA 扇区源接口。
- 实现带 32 扇区内部缓存的整盘连续 CDDA 流，在减少重叠校验回读的同时保持 Windows 原始 CDDA 接口兼容。
- 连续流支持任意采样帧位置定位，不需要在轨道边界重建数据源。
- 使用合成递增帧序列验证跨轨读取无漏帧、插帧和重复帧。
- 使用 `IOCTL_CDROM_RAW_READ` 和 CDDA 模式实现 Windows 原始音频扇区读取。
- 实现原始 CDDA 读取诊断探针。
- 确认 Windows 原始 CDDA 数据可直接按 PCM16LE 使用，并实现显式格式适配接口。
- 实现事件驱动的 WASAPI 共享模式输出，输入格式固定为音频 CD 原生的
  44.1 kHz、16 位、双声道 PCM。
- 实现播放后台组件：自动选择已就绪的音频 CD，可指定音轨和播放时长。
- 实现预分配的有界 SPSC PCM16 环形缓冲，生产和消费操作均不分配内存、不阻塞。
- 将光盘读取移至独立生产线程，以约 6 秒缓冲和 3 秒首播水位隔离光驱抖动。
- 播放范围可覆盖连续音频轨区间；轨道边界不重建扇区源、连续流或 WASAPI 会话。
- 增加 `--all`、音轨内起始偏移和 `Ctrl+C` 取消；取消可中断 WASAPI 事件等待。
- 实现 Win32、Direct2D 与 DirectWrite 原生播放器界面，接入真实 TOC、曲目选择、播放控制、进度定位和光驱弹出。
- 实现 Windows CD-TEXT 读取、pack 排序与跨 pack 文本拼接，并将专辑、艺术家和曲名接入界面。
- 实现 MusicBrainz TOC 模糊匹配、候选版本时长评分和后台元数据补全。
- MusicBrainz 自动采用要求平均每轨误差不超过 2 秒且任一轨不超过 5 秒；换盘后丢弃上一张盘的迟到结果。
- 实现 GnuDB/CDDB Disc ID 计算、HTTPS `query`/`read` 两阶段查询和协议 6 UTF-8 xmcd 解析；仅采用精确匹配结果。
- 实现 iTunes 专辑及曲目查询，并以专辑/艺术家、音轨数、编号和 TOC 时长差做保守校验。
- 实现 MusicBrainz 与 GnuDB 并行查询、iTunes 条件补全的在线元数据聚合器；界面显示实际命中的来源。
- 接入 Cover Art Archive 1200px 正面封面，并通过 WIC 圆角渲染和本地应用数据缓存复用。
- 原始 CDDA 读取改用 Windows 重叠 I/O，取消时通过 `CancelIoEx` 中断待处理读取。
- WASAPI 输出改为预填后显式启动，正常 EOS 才排空，取消和错误直接停止。
- 消费端检查 WASAPI padding；非 EOS 状态耗尽端点缓冲会记录为欠载失败。
- 实现平台无关的可靠 CDDA 扇区源：单次逻辑读取最多尝试 3 次，连续块额外读取
  1 个重叠扇区并逐字节校验，不一致时重新读取且不向播放端交付可疑数据。
- 将取消状态与普通 I/O 错误分离，避免换盘或停止播放后继续无意义重试。
- 播放后台组件输出逻辑读取、设备读取、重试、重叠校验、不一致、生产端饥饿、
  WASAPI 端点欠载和最低排队帧数等诊断统计。
- 实现平台无关的正式播放状态机，覆盖打开、缓冲、播放、排空、停止、完成、
  取消和失败状态；非法事件不会改变当前状态。
- 将光驱选择、连续流、生产线程、环形缓冲、WASAPI 消费、取消和统计收敛到可复用的
  `CddaPlaybackEngine`；对外提供阻塞式播放、跨线程停止请求和采样帧进度快照。
- 命令行播放后台组件缩减为参数解析、控制台取消和诊断结果展示，不再持有音频管线实现。
- 图形界面改为在工作线程中直接调用进程内播放引擎；播放、停止、定位、切轨、刷新、
  弹出和窗口关闭均走协作取消，不再创建或强制终止播放子进程。
- 播放进度新增实际渲染帧计数：使用已提交帧减去 WASAPI padding，正常排空后精确落到
  目标采样帧；UI 据此更新当前曲目和曲内进度，不再依赖墙上时间推测。
- 添加基础单元测试并接入 CTest。

## 本次验证结果

- CMake 使用 Ninja/MSVC 成功配置。
- MSVC Debug 构建成功。
- `make release` 可完成 Release 配置、全量/增量构建和测试；已验证中文 MSVC
  环境下修改公共头文件会正确触发所有依赖目标重编译。
- CTest：2/2 测试程序通过。平台无关测试覆盖时间转换、边界、溢出、TOC、GnuDB、
  xmcd、CDDA 重试/短读/取消/重叠策略和播放状态机；Windows 测试覆盖播放结果语义、
  无设备访问的请求边界、引擎复用后进度清零及全部诊断枚举名称。
- 已验证系统光驱枚举能力。
- 无介质时 TOC 读取返回“设备未就绪”；该错误路径工作正常。
- 使用真实音频 CD 成功读取 TOC 和原始 CDDA 数据。
- 使用可靠读取链路完成 5 秒实体光盘播放：12 次逻辑/设备读取交付 384 个扇区，
  11 次连续块重叠校验全部一致，生产端饥饿和 WASAPI 端点欠载均为 0。
- 播放逻辑提取为 `CddaPlaybackEngine` 后再次完成 5 秒实体光盘回归：提交 220,500 帧，
  12 次设备读取、11 次重叠校验均成功，生产端饥饿和端点欠载仍为 0。
- 实体盘协作取消测试通过：播放进入活动状态后由另一线程请求停止，最终状态为
  `cancelled`，没有强制终止进程。
- 图形界面进程内播放集成回归通过：播放时新增 3 个引擎/生产/取消线程，停止后线程数
  恢复；全程窗口响应正常、旧版 `CD.404.Playback` 子进程数为 0，最终以退出码 0 关闭。
- 原始读取一次成功取得 16 个扇区，共 37,632 字节。
- 连续流在真实光盘上成功跨越相邻音轨读取三个采样帧，期间未重建扇区源。
- 合成跨轨测试使用不规则读取块通过轨道边界，并逐帧验证完整序列。
- PCM 格式测试覆盖有符号边界样本、帧对齐、目标缓冲区容量和空输入。
- 使用真实音频 CD 完成从原始扇区读取、PCM 适配到默认 WASAPI 端点的 5 秒试播，
  所有请求帧均已写入并正常排空。
- 环形缓冲测试覆盖环绕、部分传输、满/空/EOS/reset，并发传输 50,000 帧时逐帧
  验证无丢失、重复和重排。
- 使用 6 秒有界缓冲完成 8 秒实体光盘流式播放，共提交 352,800 帧，验证不依赖
  整段预读。
- 从实体光盘某音轨边界前开始播放并越过边界，共连续提交 264,600 帧；期间保持
  同一个 CDDA 连续流和 WASAPI 会话。
- 使用实体 9 音轨 CD 验证在线链路：MusicBrainz 与 iTunes 均成功匹配同一专辑；GnuDB 服务请求成功，但该光盘没有条目，未产生错误补全。
- 使用无 CD-TEXT 的 9 音轨 Märchen EP 刻录盘复测误匹配：MusicBrainz 返回候选平均每轨误差 22.2 秒、最大 47.1 秒，现已按阈值拒绝，不再显示错误专辑。

受限自动化环境可能阻止 MSBuild FileTracker 访问部分系统资源；遇到这种情况可使用 Ninja/MSVC 预设。该限制不影响普通开发终端使用 Visual Studio 生成器预设。
